## From the catalogue

The approved catalogue holds browsers, editors, the password manager, the VPN client and the common tooling for each role. These install without approval.

## Anything else

File an operations request naming the software, the version and what you need it for. IT checks the licence and the security posture and usually answers within two business days.

## Developer packages

Language runtimes and package managers are in the catalogue. A package pulled by a build tool is allowed, but reviewing dependencies for known vulnerabilities before adding them is required, as the information security policy says.

## Never allowed

- Unapproved remote access tools.
- Anything that bypasses endpoint protection or monitoring.
- Cracking tools, or software from a source without a publisher.
- Software on a customer-facing system that has not had a security review.

## After you install

Keep software current. Automatic updates must stay on; a tool that only works with updates off needs an exception approved by security.
