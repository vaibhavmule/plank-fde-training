## Signing in

Use the company single sign-on provider for every work application. Your work account is your email address, and the password is held by the identity provider, not by WorkBot.

## Multi-factor authentication

Every work account needs multi-factor authentication. Use the authenticator app rather than SMS. A lost phone is handled as a device incident: report it the same day so the security team can revoke sessions.

## When SSO fails

1. Check that you can sign in to another company application; if that works, the problem is one application.
2. Clear the browser session and try a private window.
3. Try the second browser if you have one configured.
4. File an operations request with the error code and the time.

A sign-in problem affecting more than one person is a high-priority request.

## Password resets

The identity provider's self-service reset covers a forgotten password. WorkBot cannot reset it for you. If the reset email does not arrive, check the alternate address on your profile, then contact IT.

## Access for contractors

Contractor accounts expire on the contract end date. An extension is a request with the new end date, filed at least five business days before it expires.
