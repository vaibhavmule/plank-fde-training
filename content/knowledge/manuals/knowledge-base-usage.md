## What it searches

The assistant reads the whole knowledge base: policies, manuals, IT guides, customer FAQs and people guides. It searches by meaning and by words, opens the sections it needs, and quotes what it finds.

## How to ask

Ask the question you would ask a colleague, with the detail that narrows it: "Can a support agent refund $250 without approval?" gets a better answer than "refund question".

## Citing

An answer names the document and section it came from. If an answer has no citation, treat it as a suggestion and check the document yourself.

## When it says it does not know

That means the corpus has no document covering the question. File a request with the owning team so the gap gets a document, rather than repeating the question.

## What it will not do

It will not approve, refund, change a request or send a customer message. It reads and answers; actions belong to the workflow that owns them.

## Reporting a bad answer

Send the question, the answer and the document it cited to the operations team. Wrong answers are fixed by fixing the document, not by re-asking.
